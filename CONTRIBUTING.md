# Contributing

Thanks for helping improve the open-source SaaS alternatives catalog.

## What You Can Contribute

- Suggest a useful open-source alternative to a paid SaaS product.
- Add an existing independent project to the catalog.
- Correct an inaccurate status, category, description, or link.
- Improve documentation, comparisons, and project-entry templates.
- Report a broken repository link or an outdated claim.

You do not need to be the original author of an alternative to suggest it. The project must be genuinely open source, useful, and represented accurately.

## Adding A Project

1. Verify that the project has a public source repository and a clear license.
2. Confirm that the repository README explains installation and current limitations.
3. Use the format in `docs/project-entry.md`.
4. Use a real repository URL. Do not create placeholder links that look published.
5. Choose the most honest maturity and status values.
6. Open a pull request explaining why the project belongs in the collection.

Planned projects may be listed without a repository link, but they must be clearly marked as planned.

## Accuracy Rules

- Do not claim feature parity without checking the project.
- Do not hardcode frequently changing pricing unless the claim is maintained and sourced.
- Do not copy project source code or duplicate its full README.
- Keep the catalog concise and link to each project's own documentation.
- Mention important limitations, especially for self-hosted infrastructure.

## Pull Requests

Keep pull requests focused. Include the reason for a new entry or correction, verify links, and update the relevant table and detail section together. Documentation-only changes are welcome.

## Issues

Use issues for broken links, incorrect information, new alternative suggestions, or catalog improvements. Include enough context for someone else to verify the report.
